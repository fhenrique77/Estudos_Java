# Estudos de Java

Exercícios introdutórios de Java. Cada arquivo contém uma classe com `main` e pode ser executado separadamente.

## Exercícios

1. [Cálculo de moedas](Exercicio01_CalculoMoedas.java): soma a quantidade de centavos de moedas de diferentes valores.
2. [Olá, mundo](Exercicio02_OlaMundo.java): imprime uma mensagem no console.
3. [Exibir idade](Exercicio03_ExibirIdade.java): declara uma idade inteira e a imprime.
4. [Tipos de dados](Exercicio04_TiposDeDados.java): declara e imprime valores `String`, `int`, `double`, `char` e `boolean`.
5. [Apresentação pessoal](Exercicio05_ApresentacaoPessoal.java): monta frases com nome, idade, curso e semestre.
6. [Cadastro com Scanner](Exercicio06_CadastroComScanner.java): lê nome, idade, curso e semestre digitados pelo usuário.
7. [Maioridade](Exercicio07_Maioridade.java): usa `if` e `else` para verificar se uma idade é de pelo menos 18 anos.
8. [Classificação de nota](Exercicio08_ClassificacaoNota.java): informa aprovação, recuperação ou reprovação conforme a nota digitada.
9. [Validação de login](Exercicio09_ValidacaoLogin.java): compara nome e senha digitados com valores definidos no código.
10. [Controle de acesso](Exercicio10_ControleAcesso.java): verifica nome, maioridade e autorização para permitir o acesso.
11. [Desconto para estudante ou menor](Exercicio11_DescontoEstudanteOuMenor.java): concede desconto quando a pessoa é menor de idade ou estudante.
12. [Entrada com ingresso](Exercicio12_EntradaComIngresso.java): permite a entrada de adultos com ingresso ou de menores com ingresso acompanhados dos pais.
13. [Menu bancário](Exercicio13_MenuBancario.java): apresenta opções de saldo, depósito, saque e saída usando `switch`.
14. [Depósito e saque](Exercicio14_DepositoESaque.java): lê valores de depósito ou saque e calcula um novo saldo.
15. [Menu bancário com repetição](Exercicio15_MenuBancarioRepeticao.java): repete o menu de saldo, depósito e saque até a opção de sair.
16. [Contagem regressiva](Exercicio16_ContagemRegressiva.java): imprime os números de 9 até 0 com `for`.
17. [Tabuada](Exercicio17_Tabuada.java): lê um número e imprime sua tabuada de 1 a 10.
18. [Menu com do-while](Exercicio18_MenuDoWhile.java): repete um menu simples até o usuário escolher sair.

## Como executar

É necessário ter o JDK instalado. No terminal, dentro desta pasta, compile e execute a classe desejada. Exemplo:

```sh
javac Exercicio17_Tabuada.java
java Exercicio17_Tabuada
```

As [anotações](anotações.txt) reúnem conceitos básicos usados nos exercícios.
